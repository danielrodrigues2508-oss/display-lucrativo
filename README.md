21. FAQ
==================================================

Título:

"Ainda está com alguma dúvida?"

Usar accordion elegante.

Pergunta 1:

"Eu nunca vendi nada. Consigo?"

Resposta:

"Sim.

O método foi desenvolvido para quem está começando.

O Display Interativo é um produto visual e se vende sozinho quando o comerciante bate o olho e entende para que serve.

Você recebe o roteiro e aprende como fazer a abordagem."

IMPORTANTE:
Manter o conceito "se vende sozinho".

Pergunta 2:

"Trabalho o dia inteiro. Consigo fazer?"

Resposta:

"Sim.

A proposta é justamente trabalhar com 1 hora por dia.

Pode ser no horário de almoço, depois do expediente ou em outro período disponível."

Pergunta 3:

"Como recebo meu Display de Demonstração?"

Resposta:

"É simples.

Assim que você comprar a Comunidade Display Lucrativo, você informa seu CEP e endereço completo na própria plataforma.

No checkout, você poderá selecionar o Order Bump do frete do Display de Demonstração, pagando apenas a taxa de envio correspondente à sua região.

Os pedidos são organizados uma vez por semana, sempre às sextas-feiras.

Após o fechamento do lote, seu Display será produzido e enviado em 2 a 3 dias úteis, diretamente para o endereço informado.

Enquanto isso, seu acesso à comunidade é liberado imediatamente, então você já pode assistir às aulas, aprender o método, participar das mentorias ao vivo e se preparar para fazer suas primeiras abordagens."

Pergunta 4:

"Preciso comprar estoque?"

Resposta:

"Não.

Você vende, envia o pedido para nosso time e cuidamos da produção e do envio.

O Display será enviado para a sua casa, e você faz a entrega para o seu cliente."

Pergunta 5:

"Tem fidelidade?"

Resposta:

"Não.

R$37 por mês, sem fidelidade e com cancelamento a qualquer momento."

Pergunta 6:

"E se eu entrar e não conseguir vender nada?"

Resposta:

"Você está protegido pela nossa garantia.

Se em até 7 dias você conhecer o conteúdo e decidir que não é para você, pode solicitar o reembolso dentro do prazo da plataforma.

E, se você aplicar o método, utilizar o Display de Demonstração e seguir o passo a passo durante 7 dias sem conseguir vender nenhum Display para recuperar o valor da assinatura, entra em ação a minha garantia condicional de resultado.

O risco é meu."

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
